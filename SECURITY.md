# Security Policy

## Reporting Vulnerabilities

We take the security of CD & Co ERP (FinancePY) seriously. If you discover a security vulnerability, please report it to us responsibly rather than opening a public issue.

### Contact Information

Please report security issues by emailing:
- **Email:** security@cdco.com.py

Please include as much information as possible to help us reproduce and fix the issue:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any proof-of-concept code or screenshots

### Response SLA

- **Acknowledgment:** We aim to acknowledge receipt of security reports within **48 hours**.
- **Assessment & Triage:** We will evaluate the report and provide an initial assessment within **5 business days**.
- **Fix & Disclosure:** We work to resolve confirmed vulnerabilities promptly depending on severity and impact.

---

## Out of Scope

The following types of issues are considered out of scope for security reports:

- Automated vulnerability scanning reports (e.g. raw output from scanners without verified exploitability).
- Denial of Service (DoS/DDoS) attacks or rate-limiting concerns on public non-critical endpoints.
- Spam, social engineering, or phishing attacks against employees or users.
- Vulnerabilities affecting outdated or unsupported third-party components without a practical exploit path.
- Publicly known non-sensitive keys or environment variable placeholders (such as public anonymous tokens intended for client-side use).

Thank you for helping keep our software secure!
